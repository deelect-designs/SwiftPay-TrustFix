# SLIDE 5 — FRICTION AUDIT

| Friction | User Concern |
|---|---|
| Security uncertainty | Is this safe? |
| Unclear navigation | Where do I send money? |
| Recipient uncertainty | Is this the correct person? |
| Fee uncertainty | What will I pay? |
| Total uncertainty | How much leaves my account? |
| Weak confirmation | Did it work? |
