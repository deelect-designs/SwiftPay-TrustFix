SWIFTPAY TRUSTFIX

A-I-P Proposal

A consultative UX strategy connecting business assessment, user insight and an evidence-driven redesign plan.

The Business Challenge

SwiftPay is a fictional fintech application experiencing a reported 60% user drop-off.

The exact cause of the drop-off is not provided. Trust and uncertainty are therefore treated as hypotheses requiring validation through research and testing.
A

Assessment

Identify friction across login, navigation, recipient verification, fees, confirmation and transaction feedback.

I

Insight

Users need clear information and visible control at critical financial decision points.

P

Plan

Redesign the experience around security, clarity, verification, transparency, confirmation and feedback.

Key UX Interventions

Secure Connection

Communicate security clearly at login.

Account Protected

Make account security status visible.

Recipient Verified

Help users verify who will receive the money.

Transparent Fees

Display the transfer fee before confirmation.

Clear Total

Show the complete amount before the user commits.

Transaction Reference

Give users a clear record after successful completion.

Success Measurement

Metric Purpose
Transaction completion rate Measure successful completion of the core task
Login completion rate Identify login friction
Abandonment rate Identify where users leave the journey
Task completion time Measure efficiency
Error rate Measure incorrect or repeated actions
Trust score Measure perceived confidence after usability testing
