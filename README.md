# SwiftPay TrustFix

## A Trust-Centered Fintech UX Redesign

SwiftPay TrustFix is a UI/UX design capstone project focused on redesigning a fintech experience around clarity, transparency, security communication, and user confidence.

The capstone brief presents SwiftPay as experiencing a reported 60% user drop-off. This project performs a friction audit and proposes a trust-centered redesign of the Login, Home Dashboard, and Transaction experience.

---

## Project Overview

### Problem

Users may hesitate or abandon financial transactions when they are uncertain about:

- Whether their account is secure
- Whether the recipient is correct
- How much they will be charged
- What will happen after pressing Send
- Whether their transaction was successful
- Where to find transaction records

The exact cause of the reported 60% drop-off is not established by the capstone brief. Therefore, trust and uncertainty are treated as UX hypotheses requiring validation rather than proven causes.

---

## Design Challenge

> How might we make SwiftPay users feel confident, informed and in control before completing a financial transaction?

---

## UX Hypothesis

If SwiftPay makes security status, recipient verification, transaction fees, total cost, confirmation details and transaction references visible at the appropriate moments, users may experience less uncertainty and cognitive friction.

This hypothesis should be validated through usability testing and product analytics.
