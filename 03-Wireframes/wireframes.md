# SwiftPay TrustFix — Low-Fidelity Wireframes

## Purpose

The low-fidelity wireframes were created to establish information hierarchy and user flow before applying visual styling.

The wireframes focus on:

- Content hierarchy
- Navigation
- Primary actions
- Transaction information
- Trust signals
- Error prevention
- Confirmation
